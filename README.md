# 📦 IronFit – Portfolio Project

## 📌 Overview

IronFit is a full-stack e-commerce web application developed as a personal portfolio project. It simulates a fitness-oriented online store with complete user flows, including authentication, product browsing, cart management, and payment processing.

The project demonstrates the implementation of a real-world architecture using modern web development technologies.

---

## 🧱 Tech Stack

### Frontend
- Next.js
- React
- JavaScript
- Stripe.js

### Backend
- Node.js
- Express.js
- JWT Authentication
- Nodemailer

### Database
- MySQL
- Adminer

### DevOps
- Docker / Docker Compose

---

## ⚙️ Key Features

### 🔐 Authentication
- User registration and login system
- Secure JWT-based authentication
- Protected routes and session handling

### 🛒 E-commerce Logic
- Product listing and detail pages
- Shopping cart functionality
- Order creation workflow

### 💳 Payment Integration
- Stripe payment gateway (test mode)
- Secure checkout process

### 📧 Email Notifications
- Automated emails using Nodemailer
- User communication after actions (e.g. orders)

### 🗄️ Database System
- Relational database design (MySQL)
- Seeded demo data using SQL scripts

### 🐳 Containerization
- Dockerized MySQL database
- Easy local environment setup with Docker Compose
